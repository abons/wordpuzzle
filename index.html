Word Cross

The Android app

Word Cross is also a tiny (~92 KB) native Android app, and it is moving to Google Play — until that listing is live there is no way to install it for the first time. If you already have it, keep it: it works offline and nothing about it expires. This page and the app share the same word data, the same daily puzzle and the same leaderboard. The releases page lists what changed per version.
